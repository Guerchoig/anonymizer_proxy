# Anonymizer Proxy — Пульт управления (VS Code extension)

Вспомогательное расширение VS Code для явного управления анонимизацией
через [Anonymizer Proxy](../README.md). Показывает активные сессии и даёт
кнопки для работы с ними. Не требует набора команд — только просмотр списка
и нажатие кнопок.

## Что делает

1. Опрашивает прокси (`GET /api/sessions`) и показывает список активных сессий
   (session_id, время, количество маппингов) в сайдбаре и в статус-баре.
2. Для каждой сессии доступны действия:
   - **Открыть .md** — открыть анонимизированный файл ревью в редакторе;
   - **Отправить** — отправить анонимизированный промпт в облако
     (`POST /api/send`), результат де-анонимизируется прокси;
   - **Де-анонимизировать файл** — заменить плейсхолдеры в указанном файле
     (`POST /api/deanonymize_file`).

## Сборка и запуск

```powershell
cd vscode-extension
npm install
npm run compile
```

Затем в VS Code: **Run → Start Debugging** (`F5`) — запустится окно Extension
Development Host с расширением.

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| `anonymizerProxy.baseUrl` | `http://127.0.0.1:8081` | Базовый URL прокси |
| `anonymizerProxy.apiToken` | (пусто) | `PROXY_API_TOKEN` для `/api/*` (если задан в `.env` прокси) |
| `anonymizerProxy.pollIntervalMs` | `2000` | Интервал опроса списка сессий |

Если прокси слушает `localhost` без `PROXY_API_TOKEN`, токен можно оставить
пустым — `/api/*` эндпоинты будут доступны без авторизации.

## Требования

- Запущенный Anonymizer Proxy (`python -m anonymizer_proxy.main`).
- Прокси в режиме `passthrough` (`ANONYMIZER_MODE=passthrough` в `.env`) —
  анонимизация идёт через явные вызовы `/api/*` (инструменты плагина Cline
  или кнопки расширения).

## Как это работает вместе с Cline

Расширение — это пульт просмотра результата. Сам процесс анонимизации
запускается в Cline через инструменты SDK-плагина (`anonymize_text`,
`anonymize_file`, `send_prompt`, `deanonymize_file`). Расширение дополняет
его: показывает, какие сессии активны, позволяет открыть `.md` для проверки
и вручную отправить или де-анонимизировать файл.
